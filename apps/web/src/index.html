Scoring formulas

  • Impact Score = 0.25×Scale + 0.25×Scope + 0.20×Irremediability + 0.20×Likelihood + 0.10×StakeholderInput.
  • Financial Score = √(Magnitude × Likelihood).
  • Composite Score = average(Impact Score, Financial Score).
  • Quadrants use configurable defaults T_impact = 3.0 and T_financial = 3.0.
